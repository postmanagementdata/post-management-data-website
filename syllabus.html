Learning Path

Peta level & silabus lengkap

Pilih level untuk melihat cakupan materi, prasyarat, dan hasil belajar. Checklist topik merupakan catatan belajar pribadi di browser, bukan penilaian kompetensi atau sertifikasi.

Basic — Fundamental & Data Entry

Target: pemula atau pengguna yang ingin membangun fondasi Excel.
Prasyarat: mampu menggunakan komputer dan mengelola file dasar.

0/0 topik ditandai selesai

1. Pengenalan Excel & Workbook

  • Antarmuka Excel: Ribbon, Formula Bar, Name Box, Worksheet
  • Workbook, worksheet, cell, row, column, range
  • Membuat, membuka, menyimpan, dan mengelola file
  • Memindahkan, menambah, mengganti nama, dan menghapus worksheet

2. Input & Pengelolaan Data

  • Input, edit, copy-paste, AutoFill dan Fill Handle
  • Mengatur lebar kolom, tinggi baris, dan jenis data
  • Menyalin formula dan memahami referensi sel relatif
  • Freeze Panes untuk menjaga header tetap terlihat

3. Format & Struktur Tabel

  • Format Cells: Number, Date, Currency, Percentage
  • Font, alignment, border, fill, dan format tanggal
  • Membuat Excel Table dan menggunakan header
  • Sort dan Filter untuk menemukan informasi

4. Rumus & Fungsi Dasar

  • Operator aritmetika: tambah, kurang, kali, bagi
  • SUM, AVERAGE, MIN, MAX
  • COUNT, COUNTA, COUNTBLANK
  • Referensi relatif dan absolut ($A$1) sebagai pengantar

5. Pengolahan Teks Dasar

  • TRIM untuk merapikan spasi berlebih
  • UPPER, LOWER, PROPER untuk mengubah kapitalisasi
  • LEFT, RIGHT, MID untuk mengambil bagian teks
  • CONCAT atau CONCATENATE untuk menggabungkan teks

6. Visualisasi & Praktik

  • Membuat grafik Column, Bar, dan Line sederhana
  • Memilih grafik sesuai tujuan penyajian
  • Memeriksa kembali input dan hasil perhitungan
  • Praktik: rekap transaksi atau pengeluaran sederhana
✓
Hasil belajar & praktik akhirPeserta mampu membuat workbook sederhana, memasukkan dan memformat data, menggunakan fungsi dasar, mengelola tabel, serta menyajikan ringkasan dalam grafik. Praktik akhir berupa rekap transaksi/pengeluaran dengan data yang rapi dan rumus yang dapat diperiksa.
Tanya Kelas Basic ↗

Intermediate — Data Processing & Analysis

Target: pengguna yang sudah memahami dasar Excel dan ingin mengolah data lebih efisien.
Prasyarat: workbook, referensi sel, fungsi dasar, Excel Table, Sort, dan Filter.

0/0 topik ditandai selesai

1. Data Management

  • Excel Table dan structured references
  • Sort dan Filter multi-kriteria
  • Data Validation dan dropdown list
  • Conditional Formatting untuk menandai kondisi data
  • Remove Duplicates dan pengenalan Text to Columns

2. Logical Functions

  • IF untuk keputusan berdasarkan kondisi
  • AND dan OR untuk beberapa kondisi
  • IFS untuk beberapa kemungkinan hasil
  • IFERROR untuk menangani hasil error
  • Menggabungkan fungsi logika sesuai kasus

3. Conditional Functions

  • SUMIF dan SUMIFS
  • COUNTIF dan COUNTIFS
  • AVERAGEIF dan AVERAGEIFS
  • Menggunakan satu atau beberapa kriteria

4. Lookup & Data Matching

  • VLOOKUP dan HLOOKUP (pengenalan)
  • XLOOKUP pada versi Excel yang mendukung
  • Exact match dan pemilihan kolom hasil
  • Mencocokkan data antar tabel referensi

5. Text & Date Functions

  • LEFT, RIGHT, MID, LEN, TRIM, PROPER, CONCAT
  • DATE, TODAY, DAY, MONTH, YEAR
  • Mengolah dan menstandarkan teks serta tanggal
  • Membersihkan data sederhana sebelum analisis

6. Analysis & Reporting

  • Membuat dan mengatur PivotTable
  • Grouping, filter, dan ringkasan berdasarkan kategori
  • Pengenalan PivotChart dan Slicer
  • Praktik: laporan penjualan, absensi, atau operasional
✓
Hasil belajar & praktik akhirPeserta mampu membersihkan dan mengelola dataset, menerapkan formula berdasarkan kriteria, mencocokkan data dari tabel referensi, serta membuat ringkasan menggunakan PivotTable.
Tanya Kelas Intermediate ↗

Advanced — Automation & Business Reporting

Target: pengguna yang mampu mengolah dataset dan membuat ringkasan analisis.
Prasyarat: formula logika/bersyarat, lookup, Excel Table, dan PivotTable dasar.

0/0 topik ditandai selesai

1. Advanced Formulas

  • INDEX dan MATCH untuk pencarian fleksibel
  • Nested functions dan kombinasi formula
  • FILTER, UNIQUE, SORT pada Excel yang mendukung Dynamic Arrays
  • Formula tanggal: EOMONTH dan NETWORKDAYS

2. Power Query — Modul Utama

  • Menghubungkan dan mengimpor data dari sumber
  • Change Data Type, Remove Columns, Split dan Merge
  • Append Queries dan Merge Queries
  • Load hasil transformasi dan Refresh Query

3. Advanced Reporting

  • PivotTable dan PivotChart lanjutan
  • Dashboard layout dan pemilihan visual
  • KPI, tren, perbandingan, dan ringkasan performa
  • Prinsip desain laporan yang mudah dibaca

4. Workbook Control & Automation

  • Proteksi worksheet dan workbook
  • Named ranges dan pengelolaan workbook
  • Pengenalan Macro Recorder
  • Pengantar VBA sebagai modul opsional sesuai kebutuhan

5. Data Quality & Workflow

  • Memeriksa konsistensi dan kelengkapan data
  • Menentukan alur data mentah hingga laporan
  • Mendokumentasikan langkah transformasi
  • Membuat prosedur refresh dan validasi output

6. Capstone Project

  • Mengolah data mentah dari satu atau beberapa sumber
  • Membangun proses transformasi dengan Power Query
  • Membuat ringkasan dan dashboard operasional
  • Mempresentasikan hasil dan alur pembaruan data
!
Kompatibilitas & modul opsionalFitur XLOOKUP dan Dynamic Arrays bergantung pada versi Excel. Ketersediaan Power Query berbeda menurut platform dan versi. Macro/VBA memerlukan Excel Desktop; VBA bukan bagian wajib setiap kelas Advanced dan ditawarkan sebagai modul tambahan sesuai kebutuhan.

Learning Standards

Referensi & catatan kurikulum

Microsoft Support — Tugas dasar di Excel

Buka dokumentasi Microsoft ↗

Workbook, rumus sederhana, format angka, tabel, sort/filter, dan grafik dasar.

Microsoft Learn — Excel Associate (MOS)

Buka kerangka kompetensi ↗

Rujukan kompetensi mengelola workbook, cells/ranges, tables, formulas/functions, dan charts.

Microsoft Learn — Excel Expert (MOS)

Buka kerangka kompetensi ↗

Rujukan kompetensi lanjutan: workbook settings, data formatting, advanced formulas, macros, charts, dan tables.

Microsoft Support — PivotTable

Microsoft Support — Power Query

Buka panduan Power Query ↗

Dokumentasi koneksi sumber data, transformasi bertahap, pemuatan, dan refresh data.
